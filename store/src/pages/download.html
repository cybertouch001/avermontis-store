AVERMONTIS app

Apna skincare ritual, private skin diary aur poora shop, ek app mein. Version 4.0.0 for Android.

Naya kya hai (4.0)

  • Naya AVR icon — aur Me → App icon mein apna pasand ka icon chuniye.
  • Assistant chat — products, routine, order aur shipping ke sawaal English, Hinglish ya Hindi mein.
  • AR & 3D — bottle ko 3D mein ghumaiye ya apne kamre mein dekhiye, glow selfie (sirf mazaa, skin analysis nahi), aur bottle scan karke how-to-use.
  • Make an offer — apna price boliye; deal hui to sirf aapke account ke liye ek coupon.
  • Notifications — offers aur aapke order ke updates.

Download app (Android)

Install kaise karein

  1. “Download app” dabaiye aur file download hone dijiye.
  2. Download hui file kholiye aur Install dabaiye. Phone “unknown apps” ki permission maange to Allow from this source on kar dijiye.
  3. App kholiye aur sign in kijiye. Purana AVERMONTIS app phone mein hai to ye usi ko update kar dega — aapka data, diary aur login waise hi rahenge.

iPhone par: Safari mein avermontis.sites.tab.bot/app kholiye, Share dabaiye, phir “Add to Home Screen”.
